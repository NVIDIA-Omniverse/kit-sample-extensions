# Omniverse Simplified Chinese Language and Font [omni.kit.language.simplified_chinese]
Note: When the vulkan is enabled ('/app/vulkan=true'), the font overresolution size is set to 66. Otherwise, due to Direct3D's texture size limitations, the font overresolution size is limited to 44. If users want clearer fonts for specific scenes, they can config '/app/vulkan=true'.

You will also need to switch the language in the application. Go to Preferences window, click Language tab, select language in listbox & re-start for changes to take effect.
