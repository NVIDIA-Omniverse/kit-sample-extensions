# Settings

## Settings Provided by the Extension
### exts."omni.kit.window.movie_capture".available_farms.localhost Queue
- **Default Value**: http://localhost:8222
- **Description**: Specifies the URL for the local farm queue used to submit movie capture tasks.

### exts."omni.kit.window.movie_capture".ovc_mode
- **Default Value**: False
- **Description**: Indicates whether the movie capture window is operating in OVC mode.

### exts."omni.kit.window.movie_capture".queue_management_endpoint_prefix
- **Default Value**: /queue/management
- **Description**: Defines the endpoint prefix used to manage queue tasks for movie capture.

### exts."omni.kit.window.movie_capture".validate_usd
- **Default Value**: True
- **Description**: Determines if the USD stage should be checked for unsaved edits before initiating a capture.

### exts."omni.kit.window.movie_capture".settings_service
- **Default Value**: http://settings.omni-farm.svc.cluster.local
- **Description**: Specifies the URL of the settings service used for integration with the farm environment.

### exts."omni.kit.window.movie_capture".farm_job_name
- **Default Value**: create-render
- **Description**: Defines the job name that will be used when submitting a render task to the farm.

### exts."omni.kit.window.movie_capture".default_iray_subframes_per_frame
- **Default Value**: 32
- **Description**: Sets the default number of subframes per frame when using Iray for rendering in movie capture.

### exts."omni.kit.window.movie_capture".default_iray_iterations
- **Default Value**: 1
- **Description**: Specifies the default number of iterations for an Iray render task.

### exts."omni.kit.window.movie_capture".default_frame_shutter_close
- **Default Value**: 0.5
- **Description**: Configures the default shutter close timing applied during frame capture.

### exts."omni.kit.window.movie_capture".default_frame_shutter_open
- **Default Value**: 0.0
- **Description**: Configures the default shutter open timing applied during frame capture.

### exts."omni.kit.window.movie_capture".default_subframe_per_frame
- **Default Value**: 64
- **Description**: Sets the default count of subframes per frame used in general rendering tasks for movie capture.

### exts."omni.kit.window.movie_capture".default_spp_per_subframe
- **Default Value**: 1
- **Description**: Specifies the default number of samples per pixel computed for each subframe in movie capture.

### exts."omni.kit.window.movie_capture".default_spp_per_iteration
- **Default Value**: 1
- **Description**: Sets the default value for samples per pixel per iteration during movie capture rendering.

### exts."omni.kit.window.movie_capture".default_render_preset
- **Default Value**: RaytracedLighting
- **Description**: Determines the default render preset mode to be used during movie capture.

### exts."omni.kit.window.movie_capture".default_capture_type
- **Default Value**: .png
- **Description**: Sets the default file format for output files generated by movie capture.

### exts."omni.kit.window.movie_capture".fps_list
- **Default Value**: 24, 25, 30, 50, 60
- **Description**: Provides a list of supported frames-per-second options available for movie capture.

### exts."omni.kit.window.movie_capture".default_fps
- **Default Value**: 24
- **Description**: Specifies the default frame rate applied during movie capture.

## Settings Used by the Extension but Provided by Another Extension
### /persistent/exts/omni.kit.window.sequencer/useSequencerCamera
- **Description**: Controls whether the sequencer camera is used for movie capture, affecting camera dropdown population.

### /app/ovc_deployment
- **Description**: Indicates if the application is running in OVC development mode, which can change capture behavior.

### /renderer/enabled
- **Description**: Lists the renderers enabled in the application and is used to determine if specific render settings (e.g. Iray) should be available.

### /rtx-transient/rtEnabled
- **Description**: Indicates whether RTX real‑time render mode is enabled within the transient settings.

### /rtx-transient/ptEnabled
- **Description**: Indicates whether RTX path tracing render mode is enabled within transient settings.

### /rtx-transient/rt2Enabled
- **Description**: Indicates whether RTX real‑time 2.0 render mode is enabled within the transient settings.

### /rtx/rendermode
- **Description**: Defines the current RTX render mode, influencing the selection of render settings in the capture UI.

### /renderer/active
- **Description**: Specifies the active renderer used in the application’s viewport, which affects render preset selection.

### /exts/omni.kit.window.movie_capture/default_render_product
- **Description**: Determines the default render product setting applied to movie capture when using render product workflows.

### /exts/omni.kit.window.movie_capture/render_product_enabled
- **Description**: Indicates whether capture using a render product is enabled, affecting the availability of render product options.

### /exts/omni.kit.window.movie_capture/render_preset_support_render_product
- **Description**: Shows if the currently selected render preset supports render product capture functionality.

### /persistent/app/window/uiStyle
- **Description**: Specifies the current user interface style of the application, which is used to select the appropriate movie capture icons.
