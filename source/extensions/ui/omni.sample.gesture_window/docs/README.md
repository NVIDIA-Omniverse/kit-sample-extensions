# Omni.UI Sample Gestures for omni.ui.Window Extension

![](../../data/gesturewindow_prev.gif)

## Overview

This extension demonstrates how to implement gesture interactions within an `omni.ui.Window`. It provides a practical example of handling various mouse gestures (click, double-click, hover, and drag) on UI elements, with a real-time display of active gestures and custom gesture prevention.

## Key Features

- **Interactive Rectangles**: Two rectangles that respond to multiple gestures
- **Click Gesture**: Click to change color to blue/red
- **Double-Click Gesture**: Double-click to change color back to beige/olive
- **Hover Gesture**: Hover to change color to black with state feedback
- **Drag Gesture**: Click and drag to move rectangles within the window
- **Gesture Feedback**: Live display showing which gesture is currently active
- **Custom Gesture Manager**: Handles gesture prevention and conflict resolution

For complete implementation details and development guide, see the [main README](../README.md).
