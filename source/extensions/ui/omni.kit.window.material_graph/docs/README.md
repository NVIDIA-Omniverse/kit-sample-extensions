# Material Graph

Material Graph is a node-based editor for creating and editing UsdShade material networks in Omniverse Kit applications.

## User Documentation

See the [Material Graph documentation](https://docs.omniverse.nvidia.com/extensions/latest/ext_material/ext_material-graph.html) for the complete user guide.
