# Playlist Manager

![](images/ext_playlist-manager_overview.png)

| Option | Result |
|---|---|
| Method | Choose to use Waypoints or Cameras for Playback. |
| Add | Add Selected Camera/Waypoint. |
| Playback List | |
| Playback Controls | Previous: Plays Previous Item. Play/Pause: Toggles Play and Pause. Next: Plays Next Item. |
| Time per Item | Time in Seconds to wait before transitioning to next item. |
| Transition Type | Smooth: Blends from One Camera/Waypoint to the next. Cut: Direct Cut to next Item. |
| Transition Time | When using Smooth, Duration of blend in seconds. |
| Info Window | Displays Author, Date and other relevant information. |
