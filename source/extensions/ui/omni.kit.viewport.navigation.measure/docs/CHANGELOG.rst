[1.0.7] - 2026-08-13
Added
------
- Opt-in ``toggle_measurement_visibility`` setting (default off). When enabled, toggling the Measure panel with the navigation-bar button also shows/hides the completed measurements in the viewport, driving the Measure tool's transient visibility API. The user's persistent Display-menu visibility preference is left untouched. Fixes OMPE-101460 / NVBug 6456451.
