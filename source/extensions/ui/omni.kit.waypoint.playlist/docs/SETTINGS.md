# Settings

## Settings Provided by the Extension
### app/waypoint/playlist/playing
- **Default Value**: False
- **Description**: Indicates whether the current playlist is playing, and is updated when the playlist’s playing status changes.

### app/waypoint/playlist/play/enabled
- **Default Value**: True
- **Description**: Controls whether the play control is enabled based on whether the playlist is already playing or if the active playlist matches the current one.

### app/waypoint/playlist/previous/enabled
- **Default Value**: True
- **Description**: Determines if the previous control is enabled, typically turned off when a playlist is in play mode.

### app/waypoint/playlist/next/enabled
- **Default Value**: True
- **Description**: Determines if the next control is enabled, typically turned off when a playlist is in play mode.
