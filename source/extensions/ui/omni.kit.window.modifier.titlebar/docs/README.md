# Main Window Title Bar modifierExtension [omni.kit.window modifier.titlebar]
The extension to modifier the default title baar of the main window:
- App Icon, and its size
- Title string and it separator
- Image of the system buttons: Minimize, Maxmize, Close

Version family: 
103.x.x: For apps which based on Kit-SDK-103.x;
104.x.x: For apps which based on Kit-SDK-104.x.
