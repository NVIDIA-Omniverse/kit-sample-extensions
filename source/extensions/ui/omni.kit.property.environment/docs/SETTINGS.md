# Settings

## Settings Used by the Extension but Provided by Another Extension
### /rtx/iray/environment_dome_ground
   - **Description**: This setting controls the configuration of the environment dome ground for matte shadow features when using the Iray renderer.

### /rtx/shadows/enabled
   - **Description**: This setting toggles the activation of RTX shadows when the RTX rendering engine is in use.

### /renderer/active
   - **Description**: This setting determines which renderer is active within the application.

### /rtx/rendermode
   - **Description**: This setting specifies the render mode to be utilized in RTX rendering workflows.
