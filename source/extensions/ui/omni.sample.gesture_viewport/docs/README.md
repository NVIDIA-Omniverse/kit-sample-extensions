# Omni.UI Gestures for Viewport Extension

## Overview

This extension demonstrates how to implement gesture interactions in the Omniverse viewport using the `omni.ui.scene` framework. It provides a simple line manipulator that can be interacted with using mouse gestures, showcasing custom gesture managers, drag gestures, and scene UI integration.

## Key Features

- **Line Manipulator**: A draggable line in the viewport
- **Click Gesture**: Click to change line color to green
- **Double-Click Gesture**: Double-click to change line color back to beige
- **Drag Gesture**: Click and drag to move the line along the X-axis
- **Custom Gesture Manager**: Handles gesture prevention and conflict resolution
