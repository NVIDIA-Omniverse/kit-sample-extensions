# Wrapp Explorer Developer Guide

## Overview

**Wrapp Assets** are modular components designed for building virtual environments in Omniverse. They are built on top of the Universal Scene Description (USD) platform and provide a streamlined way to manage and organize assets. These assets can include USD layers, materials, textures, thumbnails, and associated metadata.

The **Wrapp Explorer extension** enables users to:
- Browse and search through Wrapp asset libraries efficiently
- Preview and configure asset properties before scene integration
- Seamlessly integrate assets into Omniverse Kit applications


## Finding Assets
Wrapp Assets are organized using a combination of names, tags, and metadata. The search functionality allows users to find assets by matching search terms against these identifiers. The search system supports both exact and partial matches, making it easy to locate assets even with incomplete search terms.

For example, searching for "table" might return results like "coffee_table", "dining_table_set", or "table_lamp" based on both the asset names and their associated tags.
