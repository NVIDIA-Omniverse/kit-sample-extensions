# Warp Core [omni.warp.core]

Exposes the NVIDIA Warp library.

After enabling, use `import warp` from Python to use Warp inside the Omniverse Python environment.

## About Warp

NVIDIA Warp is a Python framework for writing high-performance simulation and graphics code.
Compute kernels are defined in Python syntax and JIT converted to C++/CUDA and compiled at runtime.

## Documentation

The Warp documentation is hosted at [nvidia.github.io/warp](https://nvidia.github.io/warp).
