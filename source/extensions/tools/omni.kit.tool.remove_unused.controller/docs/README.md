# Remove Unused Tool [omni.kit.tool.remove_unused.controller]

This extension provides UI hooks for `omni.kit.tool.remove_unused.core` - a tool for optimizing stages in Omniverse by removing unused prims.

## UI

Presently the only place this tool can be accessed in the UI is in the `Material Browser` while on the `Stage` tab.  

Upon navigating to the Material Browser and the Stage tab, opening the options menu for the Material Browser will show an option to "Remove Unused Materials".  

Clicking this button collect all unused materials in the stage and display them as well as a count of the unused materials in a modal pop-up. This operation can then be approved or cancelled.
