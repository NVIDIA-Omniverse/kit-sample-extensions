# Overview
The Omniverse Asset Exporter is a powerful extension that enables seamless conversion of USD (Universal Scene Description) files to common 3D formats. This tool integrates directly into the Omniverse interface, providing easy access through both the File menu and content window context menu.

This extension leverages the [omni.kit.asset_converter](https://docs.omniverse.nvidia.com/kit/docs/omni.kit.asset_converter/) extension for the core conversion functionality.

## Features
- Export USD files to common 3D formats
- Support for multiple output formats:
  - OBJ
  - FBX
  - GLTF/GLB
