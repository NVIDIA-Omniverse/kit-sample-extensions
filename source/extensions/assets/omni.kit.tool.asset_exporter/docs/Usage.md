# Usage

## Requirements
- Valid USD file to export

## Installation
The Asset Exporter is included with the standard Omniverse application. No additional setup is required.

## Usage

The Asset Exporter provides a user interface for exporting USD. To use it:

1. From the Omniverse application `File` menu, select `Export`
2. Select your source file(s)
3. Configure export options
4. Click "Export" to convert to the selected output format
