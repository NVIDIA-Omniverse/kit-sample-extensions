# Overview

The Omniverse Asset Importer (`omni.kit.tool.asset_importer`) is a powerful extension that provides a unified framework for importing and converting various 3D file formats to USD (Universal Scene Description). This extension provides a uniform framework to register/manage external importers to provide a consistent import experience.

This extension leverages the [omni.kit.asset_converter](https://docs.omniverse.nvidia.com/kit/docs/omni.kit.asset_converter/) extension for the core conversion functionality.

## Features

- Built-in support for common 3D formats:
  - FBX
  - OBJ
  - GLTF
  - BVH
  - And more...
- Extensible framework for custom importer development
- Consistent import experience across different formats
- User-friendly UI interface
