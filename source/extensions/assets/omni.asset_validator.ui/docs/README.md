Omni Asset Validator (UI)
=========================

User interface for validating USD assets in Omniverse Kit applications.

![Asset Validator Window](../data/preview.png)

## Features

- Asset Validator Window for validating USD layers, folders, or live stages
- Content Browser context menus for quick validation of files and folders
- Layer Window context menus for validating layers
- Stage Window context menus for validating the current stage
- Interactive issue browsing with auto-fix suggestions
