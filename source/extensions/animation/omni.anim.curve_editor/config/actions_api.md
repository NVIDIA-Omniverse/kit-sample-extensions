# Actions in omni.anim.curve_editor

| ID                  | Display Name          | Description                          |
|:--------------------|:----------------------|:-------------------------------------|
| add_key             | Add Key               | add keys to the selected curves only |
| copy_key            | Copy Key              | copy the selected keys               |
| delete_key          | Delete Key            | delete the selected keys             |
| frame_all           | Frame All             | Frame All                            |
| frame_conditionally | Frame Selected or All | Frame Selected or All                |
| looping             | Looping               | Toggle the timeline loop             |
| next_key            | Next Key              | Next Key                             |
| paste_key           | Paste Key             | paste the copied keys                |
| previous_key        | Previous Key          | Previous Key                         |
